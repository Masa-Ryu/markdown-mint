# Markdown Mint

## **Görsel olarak yazın. Markdown'da kalın.**

VS Code için görsel bir WYSIWYG Markdown editörü.

Metinleri, tabloları, kontrol listelerini ve teknik belgeleri doğrudan görsel editörde düzenleyin; hassas denetim gerektiğinde Markdown kaynağına geçin.

Geçiş işlemi gerekmez. Mevcut Markdown dosyalarınızı açın ve yazmaya başlayın.

![Genel bakış](../media/overview.gif)

## Yazmaya odaklanın

Markdown Mint, biçimlendirme işlerinizi kolaylaştırarak içeriğe odaklanabilmeniz için tasarlanmıştır.

**Eğik çizgi komutlarını** `/` kullanarak Markdown sözdizimini yazmak zorunda kalmadan blokları ve öğeleri hızla ekleyin.

Metni seçtiğinizde, ihtiyaç duyduğunuz biçimlendirme seçeneklerini tam ihtiyacınız olan yerde sunan bağlamsal bir araç çubuğu açılır.

Klavye ile gezinme de yerleşik olarak sunulur. **Tab tuşunu** kullanarak seçilebilir öğeler arasında gezinin ve ellerinizi klavyeden ayırmayın.

Tablolarla çalışmak da aynı derecede kolaydır. Markdown sözdizimini elle düzenlemeden tablo içeriğini doğrudan kopyalayıp yapıştırın.

![Yazma özelliklerinin gösterimi](../media/focus-on-writing-demo.gif)

## Platforma özgü Markdown desteği

Markdown Mint, GitHub ve GitLab gibi platformların sunduğu Markdown özelliklerini destekler.

**GitHub Mode** (GitHub modu) ile **Alerts** (uyarı blokları) ve **Mermaid diyagramları** gibi GitHub'a özgü özellikleri doğrudan görsel editörde kullanabilirsiniz.

![Platforma özgü özelliklerin gösterimi](../media/platform-specific-demo.gif)

## Daha fazla yerleşik özellik

Markdown Mint, günlük kullanımda Markdown belgeleriyle çalışmak için ek araçlar içerir:

✅Tablolara otomatik numaralandırma ekleyin.

✅Excel veya Google Sheets'ten hücreleri kopyalayın ve doğrudan bir Markdown tablosuna yapıştırın.

✅VS Code dışındaki görselleri sürükleyip bırakarak belgenize ekleyin.

✅Otomatik öneriler ve arama ile görsel başvurularını, URL'leri ve dahili bağlantıları hızla oluşturun.

## Markdown, Markdown olarak kalır

Markdown Mint, kendine özgü kapalı bir belge biçimi getirmez.

`.md` dosyanız tek doğruluk kaynağı olmaya devam eder.

Uygun olduğunda görsel olarak düzenleyin; alttaki Markdown'ı doğrudan incelemek veya düzenlemek istediğinizde **Source** görünümüne geçin.

Görsel editörde oluşturduğunuz her şey yine Markdown'dır.

![Markdown kaynağına geçişin gösterimi](../media/markdown-stays-markdown-demo.md.gif)

## Kolay kurulum

Markdown Mint'i mevcut herhangi bir Markdown dosyasıyla kullanmaya başlayabilirsiniz.

Standart VS Code editöründe bir Markdown dosyası açıkken, dosyayı görsel editörde açmak için **Markdown Mint** düğmesine tıklayın.

Markdown dosyalarının otomatik olarak Mint'te açılması için Markdown Mint'i bu dosyaların varsayılan editörü olarak da ayarlayabilirsiniz.

![Kurulumun gösterimi](../media/easy-to-set-up-demo.gif)
