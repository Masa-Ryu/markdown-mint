# Markdown Mint

## **보이는 그대로 작성하세요. Markdown은 그대로 유지됩니다.**

VS Code용 시각적 WYSIWYG Markdown 편집기입니다.

시각적 편집기에서 텍스트, 표, 체크리스트, 기술 문서를 직접 편집하고, 세밀한 제어가 필요할 때 언제든 Markdown 소스로 전환하세요.

마이그레이션은 필요 없습니다. 기존 Markdown 파일을 열고 바로 작성을 시작하세요.

![기능 개요](../media/overview.gif)

## 글쓰기에 집중하세요

Markdown Mint는 서식 지정에 방해받지 않고 내용에 집중할 수 있도록 설계되었습니다.

**슬래시 명령** `/`을 사용하면 Markdown 문법을 입력하지 않고도 블록과 요소를 빠르게 삽입할 수 있습니다.

텍스트를 선택하면 필요한 서식 옵션을 바로 사용할 수 있는 상황별 도구 모음이 해당 위치에 표시됩니다.

키보드 탐색도 기본으로 지원합니다. **Tab 키**로 선택 가능한 요소 사이를 이동하며 키보드에서 손을 떼지 않고 작업할 수 있습니다.

표 작업도 간단합니다. Markdown 문법을 직접 수정하지 않고 표 내용을 바로 복사하여 붙여넣을 수 있습니다.

![글쓰기에 집중하는 기능 데모](../media/focus-on-writing-demo.gif)

## 플랫폼별 Markdown 기능 지원

Markdown Mint는 GitHub, GitLab 등의 플랫폼에서 제공하는 Markdown 기능을 지원합니다.

**GitHub Mode**(GitHub 모드)에서는 **Alerts**(알림 블록)와 **Mermaid 다이어그램** 같은 GitHub 전용 기능을 시각적 편집기에서 직접 사용할 수 있습니다.

![플랫폼별 기능 데모](../media/platform-specific-demo.gif)

## 더 다양한 기본 기능

Markdown Mint에는 실제 Markdown 문서 작업에 유용한 도구도 포함되어 있습니다.

✅표에 자동 번호 매기기를 추가하세요.

✅Excel이나 Google Sheets에서 셀을 복사하여 Markdown 표에 바로 붙여넣으세요.

✅VS Code 외부의 이미지를 드래그 앤 드롭하여 문서에 삽입하세요.

✅자동 제안과 검색으로 이미지 참조, URL, 내부 링크를 빠르게 만드세요.

## Markdown은 Markdown 그대로

Markdown Mint는 독자적인 문서 형식을 도입하지 않습니다.

`.md` 파일이 계속해서 유일한 원본으로 유지됩니다.

필요에 따라 시각적으로 편집하고, 기반이 되는 Markdown을 직접 확인하거나 수정하고 싶을 때는 언제든 **Source**로 전환하세요.

시각적 편집기에서 작성한 모든 내용은 여전히 Markdown입니다.

![Markdown 소스 전환 데모](../media/markdown-stays-markdown-demo.md.gif)

## 간편한 시작

기존 Markdown 파일로 바로 Markdown Mint를 사용할 수 있습니다.

VS Code의 기본 편집기에서 Markdown 파일을 연 상태로 **Markdown Mint** 버튼을 클릭하면 시각적 편집기에서 파일이 열립니다.

Markdown Mint를 Markdown 파일의 기본 편집기로 설정하여 파일이 자동으로 Mint에서 열리게 할 수도 있습니다.
