# Markdown Mint

## **Scrivi in modo visivo. Resta in Markdown.**

Un editor Markdown visuale WYSIWYG per VS Code.

Modifica testi, tabelle, liste di controllo e documentazione tecnica direttamente in un editor visuale, poi passa al sorgente Markdown ogni volta che hai bisogno di un controllo preciso.

Non serve alcuna migrazione. Apri i file Markdown che hai già e inizia a scrivere.

![Panoramica](../media/overview.gif)

## Concentrati sulla scrittura

Markdown Mint è progettato per non lasciare che la formattazione ti intralci, così puoi concentrarti sul contenuto.

Usa i **comandi slash** `/` per inserire rapidamente blocchi ed elementi senza dover digitare la sintassi Markdown.

Seleziona il testo per visualizzare una barra degli strumenti contestuale con le opzioni di formattazione che ti servono, proprio dove ti servono.

Anche la navigazione da tastiera è integrata. Usa il **tasto Tab** per spostarti tra gli elementi selezionabili senza togliere le mani dalla tastiera.

Lavorare con le tabelle è altrettanto semplice. Copia e incolla direttamente il loro contenuto senza modificare a mano la sintassi Markdown.

![Dimostrazione delle funzioni di scrittura](../media/focus-on-writing-demo.gif)

## Supporto per il Markdown specifico delle piattaforme

Markdown Mint supporta le funzionalità Markdown offerte da piattaforme come GitHub e GitLab.

Con **GitHub Mode** (modalità GitHub), puoi usare funzionalità specifiche di GitHub, come **Alerts** (avvisi) e **diagrammi Mermaid**, direttamente nell'editor visuale.

![Dimostrazione delle funzioni specifiche delle piattaforme](../media/platform-specific-demo.gif)

## Altre funzionalità integrate

Markdown Mint include strumenti aggiuntivi per lavorare con i documenti Markdown di tutti i giorni:

✅Aggiungi la numerazione automatica alle tabelle.

✅Copia celle da Excel o Google Sheets e incollale direttamente in una tabella Markdown.

✅Trascina immagini dall'esterno di VS Code e rilasciale nel documento per inserirle.

✅Crea rapidamente riferimenti a immagini, URL e collegamenti interni con i suggerimenti automatici e la ricerca.

## Markdown resta Markdown

Markdown Mint non introduce un formato di documento proprietario.

Il tuo file `.md` rimane l'unica fonte di verità.

Modifica visivamente quando ti è comodo, poi passa a **Source** ogni volta che vuoi esaminare o modificare direttamente il Markdown sottostante.

Tutto ciò che crei nell'editor visuale rimane Markdown.

![Dimostrazione del passaggio al sorgente Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Facile da configurare

Puoi iniziare a usare Markdown Mint con qualsiasi file Markdown esistente.

Quando un file Markdown è aperto nell'editor standard di VS Code, fai clic sul pulsante **Markdown Mint** per aprirlo nell'editor visuale.

Puoi anche impostare Markdown Mint come editor predefinito per i file Markdown, in modo che si aprano automaticamente in Mint.
