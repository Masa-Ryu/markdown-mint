# Markdown Mint

## **Pisz wizualnie. Pozostań przy Markdown.**

Wizualny edytor Markdown WYSIWYG dla VS Code.

Edytuj tekst, tabele, listy kontrolne i dokumentację techniczną bezpośrednio w edytorze wizualnym, a gdy potrzebujesz precyzyjnej kontroli, przełącz się na źródło Markdown.

Migracja nie jest potrzebna. Po prostu otwórz istniejące pliki Markdown i zacznij pisać.

![Przegląd](../media/overview.gif)

## Skup się na pisaniu

Markdown Mint zaprojektowano tak, aby formatowanie nie przeszkadzało w pracy i można było skupić się na treści.

Używaj **poleceń wywoływanych ukośnikiem** `/`, aby szybko wstawiać bloki i elementy bez wpisywania składni Markdown.

Zaznacz tekst, aby wyświetlić kontekstowy pasek narzędzi z potrzebnymi opcjami formatowania dokładnie tam, gdzie ich potrzebujesz.

Nawigacja klawiaturą również jest wbudowana. Używaj **klawisza Tab**, aby przechodzić między elementami, które można wybrać, bez odrywania rąk od klawiatury.

Praca z tabelami jest równie prosta. Kopiuj i wklejaj ich zawartość bezpośrednio, bez ręcznego edytowania składni Markdown.

![Demonstracja funkcji ułatwiających pisanie](../media/focus-on-writing-demo.gif)

## Obsługa Markdown charakterystycznego dla platform

Markdown Mint obsługuje funkcje Markdown udostępniane przez platformy takie jak GitHub i GitLab.

W **GitHub Mode** (trybie GitHub) możesz używać funkcji charakterystycznych dla GitHub, takich jak **Alerts** (bloki informacyjne) i **diagramy Mermaid**, bezpośrednio w edytorze wizualnym.

![Demonstracja funkcji charakterystycznych dla platform](../media/platform-specific-demo.gif)

## Więcej wbudowanych funkcji

Markdown Mint zawiera dodatkowe narzędzia przydatne w codziennej pracy z dokumentami Markdown:

✅Dodawaj automatyczną numerację do tabel.

✅Kopiuj komórki z Excel lub Google Sheets i wklejaj je bezpośrednio do tabeli Markdown.

✅Przeciągaj i upuszczaj obrazy spoza VS Code, aby wstawiać je do dokumentu.

✅Szybko twórz odwołania do obrazów, adresy URL i linki wewnętrzne dzięki automatycznym podpowiedziom i wyszukiwaniu.

## Markdown pozostaje Markdown

Markdown Mint nie wprowadza własnego, zastrzeżonego formatu dokumentów.

Twój plik `.md` pozostaje jedynym źródłem prawdy.

Edytuj wizualnie, gdy jest to wygodne, a kiedy chcesz bezpośrednio sprawdzić lub zmodyfikować źródło Markdown, przełącz się na **Source**.

Wszystko, co tworzysz w edytorze wizualnym, nadal jest Markdown.

![Demonstracja przełączania na źródło Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Łatwa konfiguracja

Możesz zacząć korzystać z Markdown Mint z dowolnym istniejącym plikiem Markdown.

Gdy plik Markdown jest otwarty w standardowym edytorze VS Code, kliknij przycisk **Markdown Mint**, aby otworzyć go w edytorze wizualnym.

Możesz też ustawić Markdown Mint jako domyślny edytor plików Markdown, aby automatycznie otwierały się w Mint.
