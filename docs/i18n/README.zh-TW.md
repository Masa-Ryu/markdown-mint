# Markdown Mint

## **所見即所得，始終是 Markdown。**

一款適用於 VS Code 的視覺化所見即所得（WYSIWYG）Markdown 編輯器。

在視覺化編輯器中直接編輯文字、表格、檢查清單和技術文件；需要精細控制時，隨時切換至 Markdown 原始碼。

無須遷移。開啟既有的 Markdown 檔案，即可開始寫作。

![功能概覽](../media/overview.gif)

## 專注寫作

Markdown Mint 旨在讓格式設定不再干擾寫作，讓你專注於內容。

使用**斜線指令** `/`，不必輸入 Markdown 語法，即可快速插入區塊和元素。

選取文字後，情境工具列會就地顯示，提供你需要的格式設定選項。

同時內建鍵盤導覽。使用 **Tab 鍵**在可選取的元素之間移動，不必離開鍵盤。

處理表格同樣簡單。直接複製貼上表格內容，無須手動編輯 Markdown 語法。

![專注寫作功能示範](../media/focus-on-writing-demo.gif)

## 支援平台專屬的 Markdown 功能

Markdown Mint 支援 GitHub、GitLab 等平台提供的 Markdown 功能。

在 **GitHub Mode**（GitHub 模式）下，你可以直接在視覺化編輯器中使用 **Alerts**（提示區塊）和 **Mermaid 圖表**等 GitHub 專屬功能。

![平台專屬功能示範](../media/platform-specific-demo.gif)

## 更多內建功能

Markdown Mint 還提供了適用於實際 Markdown 文件編輯的工具：

✅為表格加入自動編號。

✅從 Excel 或 Google Sheets 複製儲存格，直接貼入 Markdown 表格。

✅將 VS Code 外部的圖片拖放至文件中，即可插入圖片。

✅透過自動建議與搜尋，快速建立圖片參照、URL 和內部連結。

## Markdown 始終是 Markdown

Markdown Mint 不會引入專有文件格式。

你的 `.md` 檔案始終是唯一的權威來源。

需要時使用視覺化編輯；想直接檢視或編輯底層 Markdown 時，隨時切換至 **Source**。

在視覺化編輯器中建立的所有內容，依然是 Markdown。

![Markdown 原始碼切換示範](../media/markdown-stays-markdown-demo.md.gif)

## 輕鬆上手

你可以直接使用任何既有的 Markdown 檔案開始體驗 Markdown Mint。

在 VS Code 的標準編輯器中開啟 Markdown 檔案後，點選 **Markdown Mint** 按鈕，即可在視覺化編輯器中開啟該檔案。

你也可以將 Markdown Mint 設為 Markdown 檔案的預設編輯器，讓檔案自動在 Mint 中開啟。

![快速上手示範](../media/easy-to-set-up-demo.gif)
