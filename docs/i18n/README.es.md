# Markdown Mint

## **Escribe de forma visual. Sigue en Markdown.**

Un editor visual WYSIWYG de Markdown para VS Code.

Edita texto, tablas, listas de verificación y documentación técnica directamente en un editor visual, y cambia al código fuente Markdown cuando necesites un control preciso.

No necesitas migrar nada. Solo abre los archivos Markdown que ya tienes y empieza a escribir.

![Vista general](../media/overview.gif)

## Concéntrate en escribir

Markdown Mint está diseñado para que el formato no se interponga y puedas concentrarte en el contenido.

Usa los **comandos de barra** `/` para insertar bloques y elementos rápidamente sin tener que escribir sintaxis Markdown.

Selecciona texto para mostrar una barra de herramientas contextual con las opciones de formato que necesitas, justo donde las necesitas.

También incluye navegación con el teclado. Usa la **tecla Tab** para desplazarte entre los elementos seleccionables sin apartar las manos del teclado.

Trabajar con tablas es igual de sencillo. Copia y pega su contenido directamente, sin editar la sintaxis Markdown a mano.

![Demostración de las funciones de escritura](../media/focus-on-writing-demo.gif)

## Compatibilidad con Markdown específico de cada plataforma

Markdown Mint admite las funciones de Markdown que ofrecen plataformas como GitHub y GitLab.

Con **GitHub Mode** (modo GitHub), puedes usar funciones específicas de GitHub, como **Alerts** (alertas) y **diagramas Mermaid**, directamente en el editor visual.

![Demostración de las funciones específicas de cada plataforma](../media/platform-specific-demo.gif)

## Más funciones integradas

Markdown Mint incluye herramientas adicionales para trabajar con documentos Markdown reales:

✅Añade numeración automática a las tablas.

✅Copia celdas de Excel o Google Sheets y pégalas directamente en una tabla Markdown.

✅Arrastra y suelta imágenes desde fuera de VS Code para insertarlas en tu documento.

✅Crea referencias a imágenes, URL y enlaces internos rápidamente con sugerencias automáticas y búsqueda.

## Markdown sigue siendo Markdown

Markdown Mint no introduce un formato de documento propietario.

Tu archivo `.md` sigue siendo la única fuente de verdad.

Edita visualmente cuando te resulte conveniente y cambia a **Source** cuando quieras consultar o editar directamente el Markdown subyacente.

Todo lo que creas en el editor visual sigue siendo Markdown.

![Demostración del cambio al código fuente Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Fácil de configurar

Puedes empezar a usar Markdown Mint con cualquier archivo Markdown existente.

Con un archivo Markdown abierto en el editor estándar de VS Code, haz clic en el botón **Markdown Mint** para abrirlo en el editor visual.

También puedes establecer Markdown Mint como editor predeterminado para los archivos Markdown, de modo que se abran automáticamente en Mint.

![Demostración de la configuración inicial](../media/easy-to-set-up-demo.gif)
