# Markdown Mint

## **Écrivez visuellement. Restez en Markdown.**

Un éditeur Markdown visuel WYSIWYG pour VS Code.

Modifiez du texte, des tableaux, des listes de contrôle et de la documentation technique directement dans un éditeur visuel, puis passez au code source Markdown dès que vous avez besoin d'un contrôle précis.

Aucune migration nécessaire. Ouvrez simplement vos fichiers Markdown existants et commencez à écrire.

![Vue d'ensemble](../media/overview.gif)

## Concentrez-vous sur l'écriture

Markdown Mint est conçu pour que la mise en forme ne vous gêne pas et que vous puissiez vous concentrer sur le contenu.

Utilisez les **commandes slash** `/` pour insérer rapidement des blocs et des éléments sans avoir à saisir de syntaxe Markdown.

Sélectionnez du texte pour afficher une barre d'outils contextuelle avec les options de mise en forme dont vous avez besoin, à l'endroit où vous en avez besoin.

La navigation au clavier est également intégrée. Utilisez la **touche Tab** pour parcourir les éléments sélectionnables sans quitter le clavier.

Travailler avec des tableaux est tout aussi simple. Copiez et collez directement leur contenu sans modifier manuellement la syntaxe Markdown.

![Démonstration des fonctions d'écriture](../media/focus-on-writing-demo.gif)

## Prise en charge du Markdown propre à chaque plateforme

Markdown Mint prend en charge les fonctionnalités Markdown proposées par des plateformes comme GitHub et GitLab.

Avec **GitHub Mode** (mode GitHub), vous pouvez utiliser des fonctionnalités propres à GitHub, comme les **Alerts** (alertes) et les **diagrammes Mermaid**, directement dans l'éditeur visuel.

![Démonstration des fonctions propres aux plateformes](../media/platform-specific-demo.gif)

## D'autres fonctionnalités intégrées

Markdown Mint propose aussi des outils pour travailler sur des documents Markdown au quotidien :

✅Ajoutez une numérotation automatique aux tableaux.

✅Copiez des cellules depuis Excel ou Google Sheets et collez-les directement dans un tableau Markdown.

✅Glissez-déposez des images depuis l'extérieur de VS Code pour les insérer dans votre document.

✅Créez rapidement des références d'images, des URL et des liens internes grâce aux suggestions automatiques et à la recherche.

## Markdown reste Markdown

Markdown Mint n'introduit aucun format de document propriétaire.

Votre fichier `.md` reste l'unique source de vérité.

Utilisez l'édition visuelle quand cela vous convient, puis passez à **Source** dès que vous souhaitez examiner ou modifier directement le Markdown sous-jacent.

Tout ce que vous créez dans l'éditeur visuel reste du Markdown.

![Démonstration du passage au code source Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Une prise en main simple

Vous pouvez commencer à utiliser Markdown Mint avec n'importe quel fichier Markdown existant.

Lorsqu'un fichier Markdown est ouvert dans l'éditeur standard de VS Code, cliquez sur le bouton **Markdown Mint** pour l'ouvrir dans l'éditeur visuel.

Vous pouvez aussi définir Markdown Mint comme éditeur par défaut des fichiers Markdown pour qu'ils s'ouvrent automatiquement dans Mint.
