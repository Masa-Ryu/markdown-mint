# Markdown Mint

## **Пишите визуально. Оставайтесь в Markdown.**

Визуальный WYSIWYG-редактор Markdown для VS Code.

Редактируйте текст, таблицы, контрольные списки и техническую документацию прямо в визуальном редакторе, а когда нужен точный контроль, переключайтесь на исходный код Markdown.

Миграция не требуется. Просто откройте существующие файлы Markdown и начните писать.

![Обзор](../media/overview.gif)

## Сосредоточьтесь на тексте

Markdown Mint создан, чтобы форматирование не отвлекало вас от содержания.

Используйте **команды через косую черту** `/`, чтобы быстро вставлять блоки и элементы без ввода синтаксиса Markdown.

Выделите текст, чтобы открыть контекстную панель с нужными инструментами форматирования именно там, где они нужны.

Навигация с клавиатуры тоже встроена. Используйте **клавишу Tab**, чтобы перемещаться между доступными для выбора элементами, не отрывая рук от клавиатуры.

Работать с таблицами так же просто. Копируйте и вставляйте их содержимое напрямую, не редактируя синтаксис Markdown вручную.

![Демонстрация функций для работы с текстом](../media/focus-on-writing-demo.gif)

## Поддержка возможностей Markdown для разных платформ

Markdown Mint поддерживает возможности Markdown, предоставляемые такими платформами, как GitHub и GitLab.

В **GitHub Mode** (режиме GitHub) можно использовать специфичные для GitHub возможности, например **Alerts** (блоки уведомлений) и **диаграммы Mermaid**, прямо в визуальном редакторе.

![Демонстрация возможностей для разных платформ](../media/platform-specific-demo.gif)

## Другие встроенные возможности

Markdown Mint включает дополнительные инструменты для повседневной работы с документами Markdown:

✅Добавляйте автоматическую нумерацию в таблицы.

✅Копируйте ячейки из Excel или Google Sheets и вставляйте их прямо в таблицу Markdown.

✅Перетаскивайте изображения из-за пределов VS Code, чтобы вставлять их в документ.

✅Быстро создавайте ссылки на изображения, URL и внутренние ссылки с помощью автоматических подсказок и поиска.

## Markdown остаётся Markdown

Markdown Mint не вводит собственный закрытый формат документов.

Ваш файл `.md` остаётся единственным источником истины.

Редактируйте визуально, когда это удобно, и переключайтесь на **Source**, когда хотите просмотреть или изменить исходный Markdown напрямую.

Всё, что вы создаёте в визуальном редакторе, по-прежнему остаётся Markdown.

![Демонстрация переключения на исходный Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Простая настройка

Вы можете начать использовать Markdown Mint с любым существующим файлом Markdown.

Открыв файл Markdown в стандартном редакторе VS Code, нажмите кнопку **Markdown Mint**, чтобы открыть его в визуальном редакторе.

Также можно назначить Markdown Mint редактором по умолчанию для файлов Markdown, чтобы они автоматически открывались в Mint.

![Демонстрация настройки](../media/easy-to-set-up-demo.gif)
