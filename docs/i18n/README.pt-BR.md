# Markdown Mint

## **Escreva visualmente. Continue em Markdown.**

Um editor visual WYSIWYG de Markdown para o VS Code.

Edite textos, tabelas, listas de verificação e documentação técnica diretamente em um editor visual e alterne para o código-fonte Markdown sempre que precisar de um controle preciso.

Não é necessário migrar nada. Basta abrir os arquivos Markdown que você já tem e começar a escrever.

![Visão geral](../media/overview.gif)

## Concentre-se na escrita

O Markdown Mint foi projetado para que a formatação não atrapalhe e você possa se concentrar no conteúdo.

Use os **comandos de barra** `/` para inserir blocos e elementos rapidamente, sem precisar digitar a sintaxe Markdown.

Selecione um texto para exibir uma barra de ferramentas contextual com as opções de formatação de que você precisa, exatamente onde precisa delas.

A navegação pelo teclado também está integrada. Use a **tecla Tab** para percorrer os elementos selecionáveis sem tirar as mãos do teclado.

Trabalhar com tabelas é igualmente simples. Copie e cole o conteúdo das tabelas diretamente, sem editar a sintaxe Markdown à mão.

![Demonstração dos recursos de escrita](../media/focus-on-writing-demo.gif)

## Suporte ao Markdown específico de cada plataforma

O Markdown Mint oferece suporte aos recursos de Markdown disponibilizados por plataformas como GitHub e GitLab.

Com o **GitHub Mode** (modo GitHub), você pode usar recursos específicos do GitHub, como **Alerts** (alertas) e **diagramas Mermaid**, diretamente no editor visual.

![Demonstração dos recursos específicos de cada plataforma](../media/platform-specific-demo.gif)

## Mais recursos integrados

O Markdown Mint inclui ferramentas adicionais para trabalhar com documentos Markdown no dia a dia:

✅Adicione numeração automática às tabelas.

✅Copie células do Excel ou do Google Sheets e cole-as diretamente em uma tabela Markdown.

✅Arraste e solte imagens de fora do VS Code para inseri-las no documento.

✅Crie referências a imagens, URLs e links internos rapidamente com sugestões automáticas e pesquisa.

## Markdown continua sendo Markdown

O Markdown Mint não introduz um formato de documento proprietário.

Seu arquivo `.md` continua sendo a única fonte de verdade.

Edite visualmente quando for conveniente e alterne para **Source** sempre que quiser inspecionar ou editar diretamente o Markdown subjacente.

Tudo o que você cria no editor visual continua sendo Markdown.

![Demonstração da alternância para o código-fonte Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Fácil de configurar

Você pode começar a usar o Markdown Mint com qualquer arquivo Markdown existente.

Com um arquivo Markdown aberto no editor padrão do VS Code, clique no botão **Markdown Mint** para abri-lo no editor visual.

Você também pode definir o Markdown Mint como o editor padrão para arquivos Markdown, para que eles sejam abertos automaticamente no Mint.
