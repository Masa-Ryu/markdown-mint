# Markdown Mint

## **Pište vizuálně. Zůstaňte u Markdownu.**

Vizuální WYSIWYG editor Markdownu pro VS Code.

Upravujte text, tabulky, kontrolní seznamy a technickou dokumentaci přímo ve vizuálním editoru. Kdykoli potřebujete přesnou kontrolu, přepněte na zdrojový Markdown.

Žádná migrace není potřeba. Stačí otevřít stávající soubory Markdown a začít psát.

![Přehled](../media/overview.gif)

## Soustřeďte se na psaní

Markdown Mint je navržen tak, aby vám formátování nepřekáželo a mohli jste se soustředit na obsah.

Pomocí **příkazů s lomítkem** `/` rychle vkládejte bloky a prvky, aniž byste museli zadávat syntaxi Markdownu.

Vyberte text a zobrazí se kontextový panel nástrojů s potřebnými možnostmi formátování přímo tam, kde je potřebujete.

Součástí je i ovládání klávesnicí. Pomocí **klávesy Tab** přecházejte mezi prvky, které lze vybrat, aniž byste museli sundat ruce z klávesnice.

Práce s tabulkami je stejně jednoduchá. Kopírujte a vkládejte jejich obsah přímo, bez ručních úprav syntaxe Markdownu.

![Ukázka funkcí pro psaní](../media/focus-on-writing-demo.gif)

## Podpora Markdownu specifického pro jednotlivé platformy

Markdown Mint podporuje funkce Markdownu poskytované platformami jako GitHub a GitLab.

V **GitHub Mode** (režimu GitHub) můžete přímo ve vizuálním editoru používat funkce specifické pro GitHub, například **Alerts** (bloky upozornění) a **diagramy Mermaid**.

![Ukázka funkcí specifických pro platformy](../media/platform-specific-demo.gif)

## Další vestavěné funkce

Markdown Mint obsahuje další nástroje pro každodenní práci s dokumenty Markdown:

✅Přidejte do tabulek automatické číslování.

✅Zkopírujte buňky z Excelu nebo Google Sheets a vložte je přímo do tabulky Markdown.

✅Přetáhněte obrázky z prostředí mimo VS Code a vložte je tak do dokumentu.

✅Pomocí automatických návrhů a vyhledávání rychle vytvářejte odkazy na obrázky, adresy URL a interní odkazy.

## Markdown zůstává Markdownem

Markdown Mint nezavádí proprietární formát dokumentů.

Váš soubor `.md` zůstává jediným zdrojem pravdy.

Upravujte vizuálně, když vám to vyhovuje, a kdykoli chcete přímo prohlížet nebo upravovat zdrojový Markdown, přepněte na **Source**.

Vše, co ve vizuálním editoru vytvoříte, zůstává Markdownem.

![Ukázka přepnutí na zdrojový Markdown](../media/markdown-stays-markdown-demo.md.gif)

## Snadné nastavení

Markdown Mint můžete začít používat s jakýmkoli stávajícím souborem Markdown.

Když máte soubor Markdown otevřený ve standardním editoru VS Code, kliknutím na tlačítko **Markdown Mint** jej otevřete ve vizuálním editoru.

Markdown Mint můžete také nastavit jako výchozí editor souborů Markdown, aby se automaticky otevíraly v Mintu.

![Ukázka nastavení](../media/easy-to-set-up-demo.gif)
