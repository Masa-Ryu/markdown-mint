# Markdown Mint

## **Visuell schreiben. In Markdown bleiben.**

Ein visueller WYSIWYG-Markdown-Editor für VS Code.

Bearbeite Texte, Tabellen, Checklisten und technische Dokumentation direkt im visuellen Editor. Wechsle jederzeit zum Markdown-Quelltext, wenn du präzise Kontrolle brauchst.

Keine Migration nötig. Öffne einfach deine vorhandenen Markdown-Dateien und fang an zu schreiben.

![Überblick](../media/overview.gif)

## Konzentriere dich aufs Schreiben

Markdown Mint hält dir die Formatierung aus dem Weg, damit du dich auf den Inhalt konzentrieren kannst.

Mit **Slash-Befehlen** `/` fügst du schnell Blöcke und Elemente ein, ohne Markdown-Syntax eingeben zu müssen.

Markiere Text, um eine kontextbezogene Werkzeugleiste mit den passenden Formatierungsoptionen anzuzeigen – genau dort, wo du sie brauchst.

Auch die Tastaturnavigation ist integriert. Mit der **Tab-Taste** wechselst du zwischen auswählbaren Elementen, ohne die Hände von der Tastatur zu nehmen.

Die Arbeit mit Tabellen ist genauso einfach. Kopiere Tabelleninhalte und füge sie direkt ein, ohne die Markdown-Syntax von Hand zu bearbeiten.

![Demo der Schreibfunktionen](../media/focus-on-writing-demo.gif)

## Unterstützung für plattformspezifisches Markdown

Markdown Mint unterstützt Markdown-Funktionen von Plattformen wie GitHub und GitLab.

Mit **GitHub Mode** (GitHub-Modus) kannst du GitHub-spezifische Funktionen wie **Alerts** (Hinweisblöcke) und **Mermaid-Diagramme** direkt im visuellen Editor verwenden.

![Demo der plattformspezifischen Funktionen](../media/platform-specific-demo.gif)

## Weitere integrierte Funktionen

Markdown Mint enthält zusätzliche Werkzeuge für die Arbeit mit Markdown-Dokumenten in der Praxis:

✅Füge Tabellen eine automatische Nummerierung hinzu.

✅Kopiere Zellen aus Excel oder Google Sheets und füge sie direkt in eine Markdown-Tabelle ein.

✅Ziehe Bilder von außerhalb von VS Code per Drag-and-drop in dein Dokument, um sie einzufügen.

✅Erstelle mithilfe automatischer Vorschläge und der Suche schnell Bildreferenzen, URLs und interne Links.

## Markdown bleibt Markdown

Markdown Mint führt kein proprietäres Dokumentformat ein.

Deine `.md`-Datei bleibt die einzige maßgebliche Quelle.

Bearbeite dein Dokument visuell, wenn es praktisch ist, und wechsle zu **Source**, sobald du das zugrunde liegende Markdown direkt prüfen oder bearbeiten möchtest.

Alles, was du im visuellen Editor erstellst, bleibt Markdown.

![Demo des Wechsels zum Markdown-Quelltext](../media/markdown-stays-markdown-demo.md.gif)

## Einfach einzurichten

Du kannst Markdown Mint mit jeder vorhandenen Markdown-Datei verwenden.

Wenn eine Markdown-Datei im Standardeditor von VS Code geöffnet ist, klicke auf die Schaltfläche **Markdown Mint**, um sie im visuellen Editor zu öffnen.

Du kannst Markdown Mint auch als Standardeditor für Markdown-Dateien festlegen, damit sie automatisch in Mint geöffnet werden.
