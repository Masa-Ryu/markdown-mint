# Markdown Mint

## **所见即所得，始终是 Markdown。**

一款适用于 VS Code 的可视化所见即所得（WYSIWYG）Markdown 编辑器。

在可视化编辑器中直接编辑文本、表格、检查清单和技术文档；需要精细控制时，随时切换到 Markdown 源码。

无需迁移。打开已有的 Markdown 文件，即可开始写作。

![功能概览](../media/overview.gif)

## 专注写作

Markdown Mint 旨在让格式设置不再打断写作，让你专注于内容。

使用**斜杠命令** `/`，无需输入 Markdown 语法，即可快速插入块和元素。

选中文本后，上下文工具栏会就地显示，提供你需要的格式设置选项。

同时内置键盘导航。使用 **Tab 键**在可选元素之间移动，无需离开键盘。

处理表格同样简单。直接复制粘贴表格内容，无需手动编辑 Markdown 语法。

![专注写作功能演示](../media/focus-on-writing-demo.gif)

## 支持平台专属的 Markdown 功能

Markdown Mint 支持 GitHub、GitLab 等平台提供的 Markdown 功能。

在 **GitHub Mode**（GitHub 模式）下，你可以直接在可视化编辑器中使用 **Alerts**（提示块）和 **Mermaid 图表**等 GitHub 专属功能。

![平台专属功能演示](../media/platform-specific-demo.gif)

## 更多内置功能

Markdown Mint 还提供了适用于实际 Markdown 文档编辑的工具：

✅为表格添加自动编号。

✅从 Excel 或 Google Sheets 复制单元格，直接粘贴到 Markdown 表格中。

✅将 VS Code 外部的图片拖放到文档中，即可插入图片。

✅借助自动建议和搜索，快速创建图片引用、URL 和内部链接。

## Markdown 始终是 Markdown

Markdown Mint 不会引入专有文档格式。

你的 `.md` 文件始终是唯一的权威来源。

需要时使用可视化编辑；想直接查看或编辑底层 Markdown 时，随时切换到 **Source**。

在可视化编辑器中创建的所有内容，依然是 Markdown。

![Markdown 源码切换演示](../media/markdown-stays-markdown-demo.md.gif)

## 轻松上手

你可以直接使用任何已有的 Markdown 文件开始体验 Markdown Mint。

在 VS Code 的标准编辑器中打开 Markdown 文件后，点击 **Markdown Mint** 按钮，即可在可视化编辑器中打开该文件。

你也可以将 Markdown Mint 设为 Markdown 文件的默认编辑器，让文件自动在 Mint 中打开。

![快速上手演示](../media/easy-to-set-up-demo.gif)
